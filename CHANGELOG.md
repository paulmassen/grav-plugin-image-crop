# v1.0.0
##  10/19/2026

1. [](#new)
    * Initial release, for Grav 2 + Admin2 (tested on Grav 2.2.10, Admin2 2.1.35, API 1.0.51)
    * Crop icon on image thumbnails: page editor media panel, Media manager grid and list views
    * Crop editor: corner and edge handles, move, draw a new frame, aspect ratios, exact size, keyboard support
    * Save as a copy (editable name, metadata copied, unique file name) or replace the original
    * JPEG, PNG, WebP, AVIF and static GIF; EXIF orientation applied; animated GIF and oversized images refused
    * Permissions: `api.media.write` and page-level permissions
    * English and French translations
